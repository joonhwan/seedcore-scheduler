# 들여쓰기로 조직 계층을 나타내고, 사용자 줄만 "- " 로 시작합니다.
# 들여쓰기는 한 단계에 탭 하나입니다. 공백으로 맞춰도 되지만,
# 한 파일 안에서 탭과 공백을 섞으면 계층이 어긋나므로 한 가지만 쓰십시오.
# 사용자 줄은 "- 아이디, 이름" 이며 첫 쉼표만 구분자입니다.

# 아이디는 영문·숫자와 . _ - 만 3~64자로 쓸 수 있습니다 (한글 불가).
