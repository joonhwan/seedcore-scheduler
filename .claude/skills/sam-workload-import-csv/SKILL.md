# 공수표 → SAM Scheduler 가져오기 CSV

공수표의 행을 **위에서부터 한 줄로 이어 붙여** 근무일 단위 일정으로 바꾼다.
변환과 검증은 `scripts/workload-to-import-csv.mjs` 가 한다. 손으로 날짜를 계산하지 않는다.

## 1. 먼저 사용자에게 확인할 것

- **착수일.** 짐작하지 않는다. 이미 착수한 프로젝트일 수 있어 과거 날짜도 정상이다. 스크립트는 `--start` 가 없으면 멈춘다.
- **그룹(2단계) 버전이 필요한지.** 필요하면 품목 그룹 규칙 파일을 만든다(3절).

## 2. 실행 (저장소 루트에서)

```bash
node .claude/skills/sam-workload-import-csv/scripts/workload-to-import-csv.mjs \
  <공수표.csv> <출력.csv> --start 2026-11-09 [--groups <규칙.json>] [--holidays 2027-02-08,2027-02-09]
```

스크립트가 출력 파일을 서버의 `importCsv()` 와 같은 파싱 규칙으로 다시 읽어 검증한다. 검증에 실패하면 exit 1 이다.
출력 끝의 `⚠`/`ℹ` 줄(공수 0 항목, 투입인원 2명 이상 항목)은 사용자에게 그대로 전한다.

## 3. 그룹 규칙 파일

```json
{
  "rules": [
    { "pattern": "CPU", "group": "회로카드 조립체 - CPU" },
    { "pattern": "^기구물", "process": "검사", "group": "기구물 입고검사" }
  ],
  "default": "시험장비 통합 조립·시험"
}
```

- 위에서부터 처음 맞는 규칙을 쓴다. `pattern` 은 정리된 품명에 대한 JS 정규식이고, `process` 를 주면 공정까지 맞아야 한다.
- 같은 그룹은 원본 행 순서상 **붙어 있어야** 한다. 떨어져 있으면 앱에 같은 이름의 그룹이 두 개 생기므로 스크립트가 멈춘다. 예를 들어 "기구물 조립" 은 이름이 "기구물"로 시작해도 맨 뒤 통합 단계라서 `process` 로 걸러 냈다.
- 규칙 파일은 **Write 도구로 쓴다.** 셸 heredoc 은 `\\b` 를 `\b`(JSON 에서는 백스페이스)로 바꿔 규칙이 조용히 안 맞는다.

## 4. 일정 규칙 (사용자와 합의한 것 — 임의로 바꾸지 않는다)

| 항목 | 규칙 |
|---|---|
| 순서 | 행 순서대로 한 줄. 누적 시간을 8h/일로 잘라 날짜를 정한다. 12h 다음 6h 는 둘째 날이 겹치고, 0.5h 처럼 짧은 작업은 앞 작업과 같은 날에 들어간다 |
| 기간 | **투입공수**(1인당 시간) 기준. 총공수가 아니다 |
| 공수 0(미정) | 다음 날 아침부터 하루를 통째로 잡는다 |
| 휴일 | 토·일과 공휴일(스크립트 기본값 + `--holidays`)을 뺀다 |
| 제목 | `[공정] 품명`. 품명의 앞뒤 공백과 연속 공백만 정리하고, 오타는 원본 그대로 둔다 |
| 진척율 | 0% |

공정별 인원으로 병렬 배정하거나 품목 이름으로 선후관계를 추론하는 방식은 검토했다가 **사용자가 뺐다.**
사용자가 직접 요청할 때만 다시 꺼낸다.

## 5. 결과를 전달할 때 알릴 것

- **가져오기는 프로젝트의 일정 트리를 전부 지우고 새로 채운다.** 빈 프로젝트에서 실행하고, 프로젝트 MANAGER 권한(또는 관리자 모드)이 필요하다.
- 금요일에 시작해 월요일에 끝나는 작업은 간트 차트에서 주말까지 이어진 막대로 보인다. 앱은 시작일과 종료일만 저장하기 때문이다.
- 공수 0 항목은 실제 기간을 영업팀에 확인해야 한다.

## 예시 (`examples/`)

| 파일 | 내용 |
|---|---|
| `sample-workload.csv` | 입력 공수표 80행, 109.5h. 실제 공수표에서 사업·구성품 이름만 바꿨다 |
| `sample-workload.groups.json` | 그룹 규칙 10개 |
| `sample-workload_import.csv` | `--start 2026-11-09` 1단계 결과 (11-09 ~ 11-30, 근무일 16일) |
| `sample-workload_import_grouped.csv` | 같은 조건의 2단계(그룹) 결과 |

`examples/local/` 은 git 이 무시한다. **저장소가 공개(PUBLIC)라서** 실제 고객 공수표와 그 결과물은 이 폴더에만 둔다.
